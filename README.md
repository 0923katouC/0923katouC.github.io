# 0923katouC.github.io

Personal academic website hosted with GitHub Pages.

## Structure

- `index.html` — homepage
- `research.html` — research overview
- `publications.html` — publication list
- `blog.html` — blog index
- `cv.html` — CV page
- `posts/` — individual blog posts
- `assets/css/style.css` — site-wide styles
- `assets/js/main.js` — minimal JavaScript

The site uses MathJax for mathematical notation.
