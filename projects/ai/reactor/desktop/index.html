REACTOR / MAC

整机声音接入

让整台 Mac 正在播放的声音进入反应堆。音乐播放器、视频、游戏和其他应用都可以，不必逐个选择来源。

第一次使用

  1. 下载 Mac 接入器，解压后打开「声场反应堆接入器」。适用于 Apple 芯片的 Mac，系统版本需为 macOS 14.2 或更新。
  2. 打开声场反应堆网页，点击「接入整机声音」。浏览器若询问是否允许连接本机，选择允许。
  3. 在 macOS 的提示中允许接入器访问系统音频，然后在任意应用播放声音。无需选择标签页、窗口或应用。

之后怎么用

先打开接入器，再打开网页并点击「接入整机声音」。菜单栏中的「◈」可以打开网页、停止接收或退出工具。

声音只在本机分析。网页收到的是频率和强弱，不接收录音文件。关闭页面后，接收会在连接结束后停止；异常断线最迟十二秒内停止。

无法连接时

确认菜单栏已有「◈」，并检查系统设置 → 隐私与安全性 → 屏幕与系统音频录制中是否允许本接入器。网页建议使用桌面版 Chrome 或 Edge。

此工具为个人项目的本机编译版本。也可以查看源码与编译说明。其他设备仍可使用网页中的音频文件或浏览器共享入口。
