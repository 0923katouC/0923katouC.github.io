I / DEFINITIONS

先约定符号

中心质量固定，测试粒子无反作用。E 是单位质量的机械能，L = |r × v| 是单位质量的角动量大小，vᵣ = dr/dt。取参考长度 r₀，长度、时间、E、L 的单位依次为 r₀、√(r₀³/GM)、GM/r₀、√(GM r₀)。下式与图中均使用无量纲量。

E = ½(vᵣ² + L²/r²) − 1/r
II / GEOMETRY

从有效势读出轨道

径向运动满足 ½vᵣ² + Veff = E。圆轨道处于有效势的最小值；其上 E < 0 为椭圆，E = 0 为抛物线，E > 0 为双曲线。中心位于圆锥曲线的焦点，图上统一将近心点朝向 +x，沿逆时针运动。

Veff = L²/(2r²) − 1/r
e² = 1 + 2EL² · r(θ) = L²/(1 + e cos θ)
III / SCOPE

相图与展示边界

E–L 图是守恒量参数空间，并非完整相空间；它不指定轨道取向和初始相位。动画用通用变量开普勒方程按物理时间求解，无耗散、进动或相对论修正。为避开点质量碰撞奇点，此页限定 L ≥ 0.25。

开放轨道及特别大的椭圆只播放有限半径内的一段，到边界暂停。保留轨道在同一时刻经过近心点；它们离开显示窗口后隐藏，闭合轨道继续运行。
