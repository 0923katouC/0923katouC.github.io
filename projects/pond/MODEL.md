# Kerr 黑洞吸积盘：模型与验证

本项目将 **Kerr 时空中的数值光线追踪**、**相对论薄盘的稳态辐射基线**和 **一维黏性盘的时变面密度**组合成可在浏览器中交互的实验。磁场仅通过给定的有效应力改变黏性；页面没有运行 HARM、BHAC 或其他三维 GRMHD 求解器。

这些部分的精度不同：光路使用固定 Kerr 度规；物质输运使用 Newtonian、轴对称、垂直积分的薄盘扩散方程；可见纹理与颜色为显示模型。不能把这三个层次合称为完整的广义相对论磁流体模拟。

## 单位、参数与范围

- 用户界面和流体模块使用 `r_g = GM/c²`、`t_g = GM/c³`，代码中的轨道公式取 `G = M = c = 1`。自旋是无量纲 `a_* = Jc/(GM²)`；盘固定沿正方位角方向转动，负自旋表示盘与黑洞自旋反向。
- 复用的 Kerr–Schild 光路代码使用 `R_s = 2r_g = 1`，因此其内部 `M = 0.5`、`a = a_*/2`。光路位置与时间传给显示层时乘以 2，恢复 `r_g` 和 `t_g`。代码空间轴为 `(x,y,z)`，自旋轴是 `+y`，四维分量顺序是 `(x,y,z,t)`、号差是 `(+++-)`。
- 盘内缘为 `r_ISCO(a_*)`，外缘为 `40r_g`；当前相机距离为 `96r_g`。它是有限距离的静止观察者，并非严格位于无穷远。
- 交互自旋范围为 `−0.95 ≤ a_* ≤ 0.98`，给定厚度为 `0.015 ≤ h = H/r ≤ 0.15`。`h` 不是求解能量与垂直平衡方程得到的结果。
- 质量控制恢复秒、开尔文等物理单位，不改变以 `r_g` 表示的几何形状。模拟时钟以 `t_g` 计，时间流速控件给出每秒现实时间推进的 `t_g` 数量。

## 1. 光路、遮挡和频移

光子遵循固定 Kerr 度规下的零测地线。实现使用 Cartesian Kerr–Schild 坐标中的 Hamilton 方程，而不是把一个圆形阴影盖到图上：

\[
H=\frac12 g^{\mu\nu}p_\mu p_\nu=0,\qquad
\frac{dx^\mu}{d\lambda}=g^{\mu\nu}p_\nu,\qquad
\frac{dp_\mu}{d\lambda}=-\frac12\partial_\mu g^{\alpha\beta}p_\alpha p_\beta.
\]

程序由观察者局部正交标架初始化光线，以四阶 Runge–Kutta 方法向过去积分。静态几何结果被缓存；改变自旋、倾角、几何厚度等参数时重新计算光路，盘密度和纹理则可在缓存上继续变化。Kerr 零测地线的分离结构与解析参照见 [Gralla & Lupsasca (2020)](https://arxiv.org/abs/1910.12881)。当前代码并未使用该论文的椭圆函数解析求解器。

盘被视为不透明介质。发光面是 `|y| = h r` 的上下两个锥形面，只保留 `r_ISCO ≤ r ≤ 40r_g` 内的交点。光线首次从外侧进入不透明盘体即停止：进入上下光球面时记录发射，进入内外径向截断边界时吸收并返回黑色。径向边界不使用薄盘表面发射率，也不会透射出错误的下侧盘像；它们是数值截断处方，不是自洽求解的盘边缘。弯曲光路可以到达盘远侧，因此仍能出现透镜像。这里的有限厚表面是方便交互的几何处方，既不是自洽的光学深度面，也不是计算得到的垂直结构。

发射体使用赤道 Kerr 圆轨道角速度，再将其延拓到给定表面，利用当地完整度规归一化四速度。该离面运动并不是精确的离面圆测地线。红移因子由观察者和发射体实际测得的频率之比计算：

\[
g=\frac{\nu_{\rm obs}}{\nu_{\rm em}}
=\frac{-p_\mu u^\mu_{\rm obs}}{-p_\mu u^\mu_{\rm em}}.
\]

相机初始化令分子为 1。此表达式共同包含引力频移、横向多普勒效应和视线运动效应。平稳赤道圆轨道下，它化为 `g = 1/[u^t(E−ΩL_z)]`，其中 `E` 是该条相机归一化光线的守恒能量；有限距离相机情况下不应擅自将分子改成 `E`。

真空中比强度满足 `I_ν/ν³` 不变；本页面使用波段积分强度关系 `I_obs = g⁴ I_em`。显示的是归一化相对亮度，不是一个给定探测器波段中的绝对通量。相对论辐射转移及其与流体计算的区别可参见 [BHAC 的辐射后处理部分](https://arxiv.org/html/1611.09720v2#S5)。

积分有步数、空间分辨率和步长限制。特别接近临界光路的未收敛射线保留为暗像素；极窄高阶子环不保证被解析。显示阶段的有限模糊和曝光会进一步影响边缘。页面没有手绘光子环，也没有在光路计算之外添加喷流。

## 2. Page–Thorne 稳态辐射基线

在 `M=1` 单位下，以下 `a` 表示无量纲有符号自旋。赤道圆轨道的角速度、比能量和比角动量为：

\[
\Omega=\frac1{r^{3/2}+a},\qquad
D=r^{3/4}\sqrt{r^{3/2}-3\sqrt r+2a},
\]
\[
\mathcal E=\frac{r^{3/2}-2\sqrt r+a}{D},\qquad
\mathcal L=\frac{r^2-2a\sqrt r+a^2}{D}.
\]

假定几何薄、辐射有效、圆轨道主导且内缘力矩为零，由 [Page & Thorne (1974)](https://doi.org/10.1086/152990) 得到一个盘面上、当地共动系测得的辐射通量：

\[
F_{\rm NT}(r)=-\frac{\dot M}{4\pi r}
\frac{\Omega_{,r}}{(\mathcal E-\Omega\mathcal L)^2}
\int_{r_{\rm ISCO}}^r
(\mathcal E-\Omega\mathcal L)\mathcal L_{,r'}\,dr'.
\]

这里的几何因子是 `r`，不是完整四维 Boyer–Lindquist 度规行列式给出的 `r²`。`F_NT(r_ISCO)=0`，ISCO 内不延续稳定圆轨道薄盘。实现对数采样半径，使用解析轨道导数与逐段 Simpson 积分建立查找表。

恢复温度时定义名义效率 `η_NT = 1−𝓔_ISCO`，并采用：

\[
L_{\rm Edd}=\frac{4\pi GMm_pc}{\sigma_T},\qquad
\dot M_{\rm Edd}=\frac{L_{\rm Edd}}{\eta_{\rm NT}c^2},\qquad
\dot m=\frac{\dot M}{\dot M_{\rm Edd}},
\]
\[
F_{\rm physical}=F_{\rm dimensionless}
\frac{\dot M c^6}{G^2M^2},\qquad
T_{\rm eff}=(F_{\rm physical}/\sigma_{\rm SB})^{1/4}.
\]

这是本页面对 Eddington 吸积率的明确约定；别处也存在固定效率 `η=0.1` 的约定，两者数值不可直接混用。`η_NT` 未包含光子再捕获。有限外缘、非稳态扰动与显示归一化也意味着不能把页面图像积分直接当作 `η_NT Ṁc²`。

## 3. 真正随时间推进的一维流体部分

盘面密度由 [Pringle (1981)](https://doi.org/10.1146/annurev.aa.19.090181.001033) 的 Keplerian 黏性扩散方程演化：

\[
\frac{\partial\Sigma}{\partial t}
=\frac3r\frac{\partial}{\partial r}
\left[\sqrt r\frac{\partial}{\partial r}
(\nu\Sigma\sqrt r)\right],\qquad
\dot M_{\rm inward}=6\pi\sqrt r\frac{\partial}{\partial r}
(\nu\Sigma\sqrt r).
\]

这不是沿着圆轨道播放粒子动画。注入气体环会改变保存在网格中的质量；黏性输运使它向相邻网格扩散，物质可以从内边界流失。

采用 [Shakura–Sunyaev α 处方](https://ui.adsabs.harvard.edu/abs/1973A%26A....24..337S/abstract) 的给定黏性：

\[
\Omega_K=r^{-3/2},\quad H=hr,\quad c_s=H\Omega_K,\quad
\nu=\alpha_{\rm eff}c_sH=\alpha_{\rm eff}h^2\sqrt r.
\]

磁压比定义为 `β=P_gas/P_mag`，当前演示闭合明确选为：

\[
\alpha_{\rm eff}=\min(0.6,\alpha+0.3/\beta).
\]

其中 `0.3` 是所选择的参数，不是由 MRI 计算出的普适常数。β 越小，给定的附加输运越强。程序没有演化磁场、计算 Lorentz 力或检验 `∇·B=0`；也没有求出真实的 Maxwell 应力相关量。MRI 的机制见 [Balbus & Hawley (1991)](https://doi.org/10.1086/170270)，该论文用于解释研究背景，不代表页面重现了其不稳定性。

数值实现使用 128 个对数径向环形单元，储存：

\[
m_i=A_i\Sigma_i,\qquad
A_i=\pi(r_{i+1/2}^2-r_{i-1/2}^2),\qquad
\frac{dm_i}{dt}=\dot M_{i+1/2}-\dot M_{i-1/2}.
\]

界面流量由相邻单元的 `Q=νΣ√r` 差分得到。显式时间步按最大质量流出系数限制为其倒数的 `0.42` 倍，并进行子步积分，以保持非负质量。内边界取 `Q=0`；外边界固定向内供给率为 1。关闭外源时，外边界流量为 0，是无通量边界而非自由外逸边界。初态使用该离散格式自身的稳态解。

输运质量是单位供给率下的无量纲质量。`Ṁ/Ṁ_Edd` 控件用于恢复温度的物理尺度，不会另行改变外边界的无量纲供给率。改变自旋会重建内缘和整个初态；改变 α、β 或厚度保留已有质量并更新黏性。密度曲线以本次初始化的最大面密度归一化。质量账本检查：

\[
M_{\rm disk}+M_{\rm accreted}
=M_{\rm initial}+M_{\rm injected}+M_{\rm supplied}.
\]

上述守恒是离散模型内的质量守恒；它不证明完整的相对论能量与角动量守恒。

## 4. 时变流体与图像如何连接

使用网格局部耗散的代理量 `Q=νΣ√r` 相对于其稳态值 `Q_ref` 的比值来调制 NT 基线：

\[
F(r,t)=F_{\rm NT}(r)\,\frac{Q(r,t)}{Q_{\rm ref}(r)}.
\]

比值在相邻径向单元间插值。这能在初态恢复 NT 通量，也使环注入和应力改变影响发光；它是**时变 Newtonian 输运与相对论稳态辐射的混合闭合**，不是从时变 GR 辐射流体方程得到的解。局部瞬时质量流率可能因扩散而变号，因此并未把它逐点强行代入稳态 NT 公式。

显示层还叠加随 Kerr 角速度转动、有限寿命的噪声纹理，用来表现结构和差速旋转。该纹理没有反馈到守恒网格，不能作为磁湍流、MRI 增长率或密度涨落谱的数值结果。纹理相位包含光路的坐标时间延迟；径向流体剖面使用当前快照，未保存整段光程所需的流体历史，因此不是完整的时变辐射转移。

热辐射颜色为示意色，而不是逐频率积分 Planck 谱、滤镜响应或人眼响应得到的颜色。当前调色板用固定的 `2×10⁵ K` 温度参考，亮度在 NT 剖面归一化后另乘 `ṁ/0.25`，再经过曝光、色调映射和有限模糊。因此质量和吸积率变化可以影响画面，但画面仍不表示绝对光度。最高有效温度读数来自物理温标；显示颜色、屏幕亮度和该温度是不同层次的量。很多高温盘的辐射峰在紫外或 X 射线，橙金色画面不意味着肉眼会看到这样的橙色。

## 5. 验证与复现

在仓库根目录运行，无额外 npm 依赖：

```sh
node --test tests/pond-physics.test.cjs
```

已实际运行并通过以下七类检验：

1. Kerr 解析极限：`a=0` 时视界为 `2r_g`、ISCO 为 `6r_g`、ISCO 比能量为 `√(8/9)`；正、反向自旋的参考 ISCO 正确。
2. NT 通量：内缘为零，各采样点非负且有限，远区趋于 `3/(8πr³)`（单位吸积率）。
3. 离散稳态：边界持续交换质量时，内部初始剖面维持不变，质量账本闭合。
4. 环扰动：质量向相邻网格重新分布，所有单元保持非负，计入吸入质量后账本闭合。
5. 物理温标：固定自旋时 `T_eff ∝ (ṁ/M)^(1/4)`。
6. Schwarzschild 通量闭式积分：整个内盘的数值通量与独立解析结果一致。
7. 参数变化：改变应力不会凭空改变储存质量；改变自旋会重建有限网格并重置时间。

另将 `a=0`、`6≤r≤40`、256 个采样点的数值通量与 Schwarzschild 情形的闭式积分作独立核对。定义

\[
A(x)=x-\frac{\sqrt3}{2}\ln\frac{x-\sqrt3}{x+\sqrt3},\qquad
F_{a=0}(r)=\frac3{8\pi}\frac{r^{-7/2}}{1-3/r}
\left[A(\sqrt r)-A(\sqrt6)\right].
\]

排除两者均为零的内缘点，实测最大相对误差为 `7.49×10⁻⁸`。这项检查覆盖整个盘的径向形状，而不只验证远区幂律。

作为可独立对照的轨道数值：

| `a_*` | `r_ISCO/r_g` | `1−𝓔_ISCO` |
| --- | --- | --- |
| −0.9 | 8.7173522796 | 0.0389983456 |
| 0 | 6 | 0.0571909584 |
| +0.9 | 2.3208830418 | 0.1557529920 |
| +0.998 | 1.2369706552 | 0.3209941656 |

最后一行是公式参考值，不是当前交互控件的最高自旋。上述测试验证流体与径向辐射模块，不能单独证明 GPU 光路已达到研究精度。更强的光路验证还应比较 Hamiltonian 与运动常数残差、步长和像素收敛，以及无盘 Schwarzschild 捕获边界。对远处观察者，临界冲量为 `3√3 r_g`；有限距离 `D=96r_g` 的静止观察者应使用 `sin ψ=(3√3/D)√(1−2/D)`，不能直接把远处临界冲量当成画面投影半径。

2026-10-24 已在实际 WebGL2 设备执行两组 GPU 验证。`tests/pond-kerr-geodesics.html` 的 12 条光线包含非赤道 Kerr 情形，最大归一化零 Hamiltonian 残差 `6.788×10⁻⁷`、最大相对轴向角动量漂移 `4.414×10⁻⁴`、守恒能量变化为 0，步长减半后的最大出射方向向量差 `2.463×10⁻⁴`；有限距离 Schwarzschild 捕获边界测试通过。`tests/pond-gpu.html` 则运行生产盘面着色器，六组自旋/倾角/厚度组合的交点半径、延迟、频移和盘/天空/阴影分类检查均通过，高倾角的径向边缘吸收检查也通过。浮点误差和驱动差异会改变具体末位数字；这些是数值回归验证，不是完整参数域的研究级收敛证明。

## 6. 当前不包含的物理与后续路线

当前模型未包含三维 MHD/MRI、磁重联、偏振、同步辐射、自洽垂直平衡、气体/辐射能量方程、辐射反馈、Compton 散射、盘自引力、黑洞质量自旋的演化、喷流、ISCO 内的发光下落流、盘面返回辐射，以及吸收和散射的体辐射转移。在接近 Eddington 吸积率、几何厚盘或强磁压条件下，薄盘闭合尤其需要谨慎解释。

若继续推进物理保真度，可由成熟 GRMHD 求解器离线产生密度、四速度和磁场快照，再将数据接入同一网页进行相对论辐射转移。两条可复核的参考路线是 [Gammie, McKinney & Tóth (2003), HARM](https://arxiv.org/abs/astro-ph/0301509) 与 [Porth et al. (2017), BHAC](https://arxiv.org/abs/1611.09720)。引入这些数据后仍需验证网格收敛、磁场散度、能量质量通量及辐射模型；不能仅通过加密纹理获得这些物理内容。
