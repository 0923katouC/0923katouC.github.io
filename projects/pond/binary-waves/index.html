模型、单位与适用范围

轨道与初值

总质量 M = M₁ + M₂ 固定为 60 个太阳质量，两颗黑洞均取零自旋。以 GM/c² 为长度单位、GM/c³ 为时间单位，G 为引力常数，c 为光速。相对位置和速度由标准谐和坐标下的运动方程逐步积分。相对于牛顿加速度，保留到 (v/c)⁷，即 3.5 阶后牛顿近似。1、2、3 阶项决定保守运动，2.5、3.5 阶项给出引力辐射反作用。

偏心率如何设定

取初始近心距 rₚ 与远心距 rₐ，使 (rₐ + rₚ)/2 = 36 GM/c²，e = (rₐ − rₚ)/(rₐ + rₚ)。先用保守方程求出连接这两个转折点的近心点速度，再开启辐射反作用。e = 0 时从准圆轨道开始，加入相应的缓慢向内速度。图中两颗黑洞的位置按 3 阶质心关系放置，两点之差是所积分的相对轨道。

波与观测者

应变取最低阶质量四极矩辐射。h₊ 和 h× 分别描述垂直于视线、彼此旋转 45° 的两组伸缩。单独取加号偏振时，沿第一条偏振轴的两点间距相对改变 h₊/2，沿垂直方向则相对改变 −h₊/2。观测倾角 i 是轨道角动量 L 与从质心指向观测者的方向之间的夹角。L 垂直于轨道面，正向由双星绕转的右手规则确定。波形横轴已扣除到观测者的恒定光行时，右端对应当前源时间。

传播图与终点

三维图对两个远区截面采样。一个截面沿完整的轨道面 xy。另一个截面穿过角动量轴 z，在轨道面上的交线从 x 轴朝 y 轴转过 50°。对每个传播方向，用球面上沿极角增大和方位角增大的两个切向作为偏振基，从源的质量四极矩求该处的 h₊。竖直截面留有扇形开口，便于看清后方波纹。截面从 4λ₀ 延伸到 7λ₀，其中参考波长 λ₀ = 216π GM/c²。内缘对应源时间 t，半径为 R 的位置显示 t − (R − 4λ₀)/c 时的辐射，振幅按 1/R 衰减。中央窗口单独放大双星轨迹。初始波来自同一轨道向过去的积分。双星间距降到 12 GM/c² 或演化满 22 个参考轨道周期时暂停。

从位置和速度算出两条曲线

取轨道为 xy 平面。观测者的方位角固定为 0°，改变倾角 i 时，视线在 xz 平面内从 +z 转向 +x。xᵢ 和 vᵢ 分别是相对位置、相对速度沿第 i 个坐标轴的分量，r 是两星间距，μ = M₁M₂/M，D 为观测距离。横向偏振基取 (cos i, 0, −sin i) 和 (0, 1, 0)。以下公式用有量纲的位置与速度。

Sij = vivj − GM xixj/r³
h₊ = 2Gμ (cos²i Sxx − Syy)/(c⁴D)
h× = 4Gμ cos i Sxy/(c⁴D)
