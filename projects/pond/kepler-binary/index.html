三维图如何表示概率？

等时间采样，而不是沿轨迹均匀取点

三维图采用 18,000 个静态等概率样本。令平近点角 M 均匀分布，解开普勒方程 E − e sin E = M，然后取 rᵢ = aᵢ(1−e cos E)。方向通过均匀的 cos θ 和 φ 生成。使用固定的低差异序列，调参时没有重新随机抽样的闪烁。这与完整三维旋转平均的一点概率分布等价。

点数比例按等数目或质量权重分配（整数取整误差不超过 1/18000）。偏心轨道的点颜色表示所选分量叠加后的体密度 ρ(r)，使用与右下图相同的有限径向区间平均值，以对数色标显示。半透明点的数量表示概率，屏幕叠加亮度不直接等于体密度。圆轨道的体密度为 δ 分布，因此颜色改为有限的球面概率面密度 η = w/(4πaᵢ²)，重合球面先合并权重；不会将 δ 伪装成有限体密度。可选边界线只标出几何范围，没有填充的剖切面遮挡点云。三维图的点云采样不参与二维热图计算。

径向概率与三维体密度

e > 0 时，球对称三维概率体密度在 rₚ < r < rₐ 内为：

rₚ = aᵢ(1−e)，rₐ = aᵢ(1+e)
pᵢ(r) = r / [π aᵢ √((r−rₚ)(rₐ−r))]
ρᵢ(r) = pᵢ(r)/(4πr²)
∫ 4πr²ρᵢ(r) dr = 1

主图在每个分量的 [rₚ, rₐ] 内划分 640 个径向区间。使用解析累计概率 F(r) = (E−e sin E)/π，其中 E = arccos[(1−r/aᵢ)/e]，以区间概率差分别除以区间宽度 Δr 和球壳体积 ΔV，得到 p 与 ρ 的区间平均值。两者分别满足 Σ p̄ Δr = 1 与 Σ ρ̄ ΔV = 1。边界附近显示的有限高度取决于分辨率；真正的端点密度发散。

圆轨道使用精确的 δ 表示，不把它数值展宽。p 的 δ 系数是分量概率 w；ρ 的径向 δ 系数是 w/(4πaᵢ²)，其概率须对 4πr²dr 积分。重合半径合并为一个峰。

范围之外密度为零，转折处的发散可积。e = 0 时不能把这个普通函数公式直接代入；分布退化为 ρᵢ(r) = δ(r−aᵢ)/(4πaᵢ²)，支撑在球面上。再沿视线积分才得到 Σ(R)。

剖切移去固定在物体坐标中的 x > 0、y > 0、z > 0 八分之一，仅供观察；不重新归一化、不改变物理分布或二维投影。拖动只旋转相机，不推进轨道相位。

查看物理定义、平均方法与数值精度

01　双星与时间权重

令 q = M₂/M₁ ≤ 1，a 为两星相对轨道的半长轴。两颗星绕同一质心运动，具有相同周期；a₁ = aq/(1+q)，a₂ = a/(1+q)。用相对轨道偏近点角 E 参数化：

r⃗ = a (cos E − e, √(1−e²) sin E, 0)
r⃗₁ = −q r⃗/(1+q)，r⃗₂ = r⃗/(1+q)
dP = dt/T = (1−e cos E) dE/(2π)

轨迹线默认显示单位弧长概率密度 λᵢ = (dt/T)/dsᵢ，颜色在两颗星间共用标尺。它对每条完整轨道积分为 1；叠加权重作用于三维点云、p(r)、ρ(r) 及可选二维投影。切换为角概率密度后，颜色代表等真近点角区间的停留概率，而不是等弧长区间。

λᵢ a꜀ = √[(1−e cos E)/(1+e cos E)] / [2π(aᵢ/a꜀)]
dP/dν = (1−e²)^(3/2) / [2π(1+e cos ν)²]

远近心点的 λ 比为 (1+e)/(1−e)；角概率密度比则是其平方。页面所有长度均以 a꜀ 为单位。参考：UT Austin · Elliptic orbits。

02　从三维旋转到二维面密度

完整随机旋转将任意固定半径 r 的位置分布变成均匀球面。把球壳沿 z 积分投影后，投影半径 R 的累计概率有解析形式：

F(R | r) = 1 − √[1−(R/r)²]　(0 ≤ R < r)
F(R | r) = 1　(R ≥ r)
Σᵢ(R) = ⟨ 1 / [2πrᵢ√(rᵢ²−R²)] · 𝟙(R<rᵢ) ⟩ₜ

计算对 E 使用 8192 点中点积分，按 dP 加权；每个分量在其自身外半径内划分 640 个圆环，用累计概率之差除以圆环面积。这样直接计算全部朝向的平均，避免随机抽取有限条轨迹的噪声。图像显示有限圆环分辨率下的密度，边缘和尖峰高度会依赖分辨率。

等数目叠加为 Σ = (Σ₁+Σ₂)/2；质量叠加为 Σ = (Σ₁+qΣ₂)/(1+q)。单独查看一颗星时归一化为 1。均满足 ∫₂ᴅ Σ dA = 1；这是一点概率分布，不表示两颗星的位置彼此独立。质量模式乘以总质量即可得到物理质量面密度。

增强模式只改变颜色和曲线纵轴：u = ln(1+999Σ/Σₘₐₓ)/ln(1000)，不改变概率。圆轨道的球壳投影在边缘有可积发散；e > 0 的内转折半径也可形成尖峰。二维图是视线积分后的投影，不是三维分布在 z = 0 的截面。
